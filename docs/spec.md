# Assignment_1151 前三題與 Rust 共用工具庫規格

狀態：設計已確認；共用工具庫與前三題成果已實作、執行及核對，見 [稽核記錄](audit.md)。

本規格依據 Assignment_1151 的第 1–5 頁及已確認的設計討論。題目要求以「作業要求」標示；Rust、固定尺寸矩陣、Image 與自製 BMP 等選擇則屬「專案決策」。若兩者有衝突，以原始作業要求為準。

## Problem Statement（問題）

作業前三題需要把 Bézier 曲線與有方向的路徑轉成像素，並觀察幾何近似、內外判定、像素覆蓋率及取樣限制。曲線、填色與抗鋸齒必須接成可重現的流程，各題的圖表與數字也必須來自實際執行。

作業作者需要一個小型共用工具庫，統一數學運算、路徑表示、像素資料與圖檔輸出，讓前三題共用同一套邏輯。工具庫應有清楚的型別與運算語意，並保留一般影像用途。

## Solution（解法）

使用 Rust 建立共用工具庫，以固定尺寸、f64 元素的矩陣支援三次 Bézier 公式與二維幾何運算。向量共用矩陣表示；位置與顏色維持各自的語意。一般影像使用像素型別泛型與執行時指定的尺寸。

曲線經中點細分轉成折線；多子路徑透過自行實作的 scanline non-zero winding 填色轉成覆蓋率影像；supersampling 放大幾何與畫布，使用同一填色流程，再平均回最終尺寸。覆蓋率可轉成 RGB 顏色，並由自製的未壓縮 24-bit BMP 編碼器存檔。

原先首次範圍為工具庫、必要測試與小型 BMP 示範；本次依使用者授權的檢查點完成完整前三題的場景、測量、圖表、書面回答及 PDF。以下保留原始驗收要求。

### Part 1：Two Roads to the Same Curve，4 分，來源第 2 頁

#### P1-1：兩種曲線構造，1 分

1. 自行實作三次 Bézier 公式：C(t) = (1−t)³b₀ + 3t(1−t)²b₁ + 3t²(1−t)b₂ + t³b₃，t 位於 0 到 1。
2. 自行實作控制多邊形的中點構造，在 t = 0.5 分成兩條子曲線，遞迴至指定深度；將子曲線端點連成折線近似。
3. 選四個控制點，使曲線明顯彎曲並跨越畫布大部分範圍。
4. 顯示兩種構造的結果；一張疊圖足夠，但應使用仍能看見差異的淺細分深度。

**驗收輸出**：控制點及畫布資訊、公式曲線與淺層折線的疊圖。兩種結果來自各自的實作。

#### P1-2：收斂，1.5 分

1. 將中點法折線疊在公式曲線上。
2. 公式曲線相鄰取樣點的距離必須嚴格小於 0.1 px；不能只固定少量 t 值就宣稱足夠密集。
3. 對每個公式曲線取樣點，求到折線所有線段的最近距離，再取這些距離的最大值。測量方向是曲線到折線，不得倒置；也不得只比較頂點。
4. 以細分深度為自變數，記錄並報告最大誤差。
5. 增加深度直到最大誤差嚴格小於 0.5 px，報告達到門檻的深度。
6. 回答每增加一層深度時誤差遵循的規律，並比較淺層與深層是否同樣接近該規律。
7. 說明一項中點構造能提供，而預先決定公式取樣數量的方式沒有提供的能力。

**驗收輸出**：密集公式取樣的間距檢查、各深度誤差表或圖、低於 0.5 px 的深度，以及根據實測結果撰寫的兩項解釋。不預填尚未測得的誤差或收斂結論。

#### P1-3：接點，1.5 分

1. 建立三段 Bézier 組成的開放路徑，包含兩個接點。
2. 一個接點為平滑接點，另一個為角點；用一行從方向控制線的關係說明角點的原因。
3. 比較等長與明顯不等長方向控制線的版本：接點與兩側方向控制點仍須共線，以隔離長度條件的影響。
4. 並排顯示兩個版本，說明不等長版本是否仍看起來平滑；若是，解釋等長條件在形狀以外提供的性質。

**驗收輸出**：三段開放路徑示意、等長／不等長比較圖、共線條件的可核對資料與文字回答。

### Part 2：Inside and Outside，5 分，來源第 3 頁

#### P2-1：Scanline non-zero winding fill，3 分

1. 對封閉路徑自行實作逐像素列的 scanline 填色。
2. 每列求路徑 crossings，依方向累加帶正負的貢獻，在 running winding number 非零的區間填色。
3. 固定座標系中上行／下行邊何者為正貢獻，並一致使用；正負慣例任一皆可。
4. 內外測試概念中的 line 應理解為 ray，不可用完整直線同時計算兩側 crossings。
5. 不得替換為交替填區間的 even-odd 規則。
6. 必須支援多子路徑。

**驗收輸出**：能處理一般、自交及多子路徑輪廓的填色流程，並有明確的方向與共同頂點規則。

#### P2-2：自交星形，1 分

1. 使用五個頂點，沿圓周每隔一個頂點訪問，形成單一自交封閉路徑。
2. 不可使用十個內外交替頂點代替指定星形。
3. 填色、顯示結果，並報告中心 winding number。符號須符合已選定的慣例。

**驗收輸出**：指定五頂點自交星形的填色圖與中心帶符號繞數。

#### P2-3：方向與圓環，1 分

1. 建立兩個子路徑：外圓與較小的內圓。
2. 每個圓以四段三次 Bézier 描述，方向控制點沿切線距端點 0.5523 × r。
3. 使用第一題的中點構造 flatten，再進入第二題的填色流程。
4. 渲染兩次；只能改變內圈遍歷方向，所有幾何位置都必須保持不變。
5. 顯示兩張結果，報告各自的中心 winding number，並解釋差異。
6. 說明這對字型檔中字母 O 的輪廓儲存方式有何意涵。

**驗收輸出**：兩種方向版本的圓環圖、兩個中心繞數、位置不變的可核對資料，以及方向與字型儲存的解釋。

### Part 3：Landing on the Pixel Grid，6 分，來源第 4–5 頁

#### P3-I：Area coverage，2 分

1. 將第二題星形旋轉數度，約 5° 足夠，確保沒有邊正好水平或垂直。
2. Part 3 的 I 與 II 都使用同一個旋轉後星形；III 使用輪盤。
3. Supersampling 的像素值為 k × k 子位置落在形狀內的比例。
4. 本專案以寬高各放大 k 倍、形狀座標也放大 k 倍的方式執行第二題填色，再將每個 k × k 區塊平均回一像素。
5. 輸出並顯示 k = 1、2、4、8 的四張結果。後續題目中的最大 k 為 8。

**驗收輸出**：旋轉與非軸對齊條件的記錄、相同最終尺寸的四張星形圖、倍率與覆蓋率資料。

#### P3-II：Measure it，1.5 分

1. 找旋轉後星形最平緩的邊，選擇在靠近其中一端穿越該邊的像素列。
2. 避免邊的中段，因為星形核心與尖角可能使兩側都已填滿，沒有可測量的過渡。
3. 沿該像素列、順著平緩邊的方向取樣；不可改成垂直跨過邊緣的測量。
4. 若其他邊穿過同列，只顯示所選邊附近、不受其他邊干擾的局部區段。
5. 對 k = 1 與 k = 8 繪製像素值曲線，描述兩條曲線的形狀差異。
6. 在同一個已聲明的畫布尺寸上，報告 k = 1、2、4、8 的 render time，說明成本如何隨 k 成長及原因。

**驗收輸出**：所選邊、列位置與 x 範圍的記錄；兩組原始像素值及測量圖；尺寸與各 k 的時間表；對過渡形狀及成本的解釋。

#### P3-III：Where the grid loses，2.5 分

1. 建立至少 40 個向中心放射的楔形，間隙角寬與楔形角寬相同。
2. 每個楔形可由中心與圓上兩點構成三角形子路徑；整個輪盤是多子路徑。
3. 輸出 k = 1 與 k = 8 的兩張結果。
4. 若 k = 1 的輪盤中心沒有明顯失真，增加楔形數量直到可見。
5. 指出 k = 1 觀察到、超出單純鋸齒邊緣的現象。
6. 解釋為何增加 k 能改善外圈，卻不能恢復中心的楔形細節；說明向中心移動時的空間頻率變化與 Sampling Theorem 的意義。
7. 指出相關濾波器種類，以及面積覆蓋率流程在哪一步已經施加該濾波；說明其能達到與不能達到的效果。

**驗收輸出**：最終楔形數與等寬間隙設定、中心明顯失真的 k = 1 圖、對應 k = 8 圖，以及現象、頻率、取樣與濾波的回答。

## Implementation Decisions（實作決策）

### 數學與型別

- 語言使用 Rust；數學物件統一使用 f64。
- Matrix 使用固定尺寸泛型與巢狀固定長度陣列，按列儲存。提供建立、零矩陣、單位矩陣、索引、轉置、同尺寸加減及純量乘除。
- R × K 矩陣乘 K × C 矩陣得到 R × C 矩陣；尺寸不相容時無法編譯。
- Vector 是 N × 1 Matrix 的別名，共用儲存與基本運算，增加 dot、norm_squared 及 norm。
- 暫不引入自訂 MatrixLike 或 VectorLike；若未來有具體共用需求再評估。
- Point2 透過組合二維向量共用運算。點減點回傳向量，點加／減向量回傳點；中點、插值、距離、繞中心旋轉與縮放是幾何操作。
- 點到線段距離將投影限制在線段上；退化線段以端點處理。

### 曲線與路徑

- CubicBezier 接受四個控制點。公式求值使用參數冪次橫列、4 × 4 Bézier 基底與 4 × 2 控制點矩陣；可預先計算基底乘控制點。
- 中點細分是獨立構造，不使用公式取樣結果來代替。深度 0 產生兩端點；深度 d 的單段折線有 2 的 d 次方個線段。
- Subpath 以起點、連續線段或三次曲線段，以及封閉狀態表示。Path 支援多子路徑、flatten、反向、旋轉及縮放。
- Polyline 保存頂點及封閉狀態；FlattenedPath 保存多條折線子路徑。
- 反向改變遍歷順序；三次曲線兩個控制點的角色互換。幾何位置保持不變。
- 第一題容許開放路徑；Rasterizer 的填色輸入要求明確封閉。
- 密集公式取樣須以可靠的間距控制滿足小於 0.1 px 的要求，並保存實際最大相鄰距離。誤差統計使用公式取樣點到所有折線線段的最近距離。

### 影像與顏色

- Image 使用像素型別泛型，寬高在執行時決定，以連續、按列排列的像素資料儲存；像素不必實作矩陣介面。
- 共用介面包含建立、寬高、像素讀寫、列讀取及像素型別轉換。越界查詢回傳無值。
- Image 的 f64 像素實例可保存覆蓋率，並提供不重疊區塊平均；倍率須為正，寬高須可整除。
- Color 使用三個 f64 RGB 通道，通常位於 0 到 1，提供通道混合。
- 覆蓋率 a 的顏色是背景乘以 1−a，加上前景乘以 a。作業流程直接平均數值通道；首次實作不加入 gamma 轉換或 alpha 通道。

### 光柵化與像素規則

- 座標原點在左上角，x 向右、y 向下。像素中心為其整數位置各加 0.5；正旋轉角在畫面上為順時針，角度運算使用弧度。
- Rasterizer 設定最終寬高，接收 FlattenedPath 與正整數倍率，回傳最終尺寸的 f64 覆蓋率 Image。
- 基礎填色必須為 scanline non-zero winding，支援多子路徑及自交路徑；另提供帶符號繞數查詢。
- 採順時針輪廓繞數為正的慣例，反向為負；scanline crossing 貢獻與繞數查詢須一致。
- 邊的 y 範圍採下界包含、上界排除；水平邊及零長度邊不產生 crossing。同位置的貢獻合併；填色 x 區間採左界包含、右界排除。
- 畫布外的邊仍參與繞數計算，僅限制實際像素寫入範圍。
- k 為 1 時回傳二值覆蓋率；更高倍率共用同一填色流程，以放大座標及尺寸再平均的方式產生結果。

### BMP 與測量輸出

- 自行實作 24-bit、未壓縮 BI_RGB BMP。Image 的 Color 像素實例提供便利存檔入口；實際編碼集中於可接收輸出串流的模組。
- 預設使用 14-byte 檔案標頭與 40-byte 資訊標頭，不含調色盤；像素偏移為 54 bytes。
- 使用正高度與 bottom-up 列順序，輸出 BGR 通道，每列補齊為 4-byte 的倍數。標頭以 little-endian 明確序列化；檔案與像素大小包含補齊資料。
- 有限的 RGB 通道在輸出時限制到 0 到 1、乘 255、四捨五入並轉成 8-bit。非有限通道值回傳錯誤。
- 作業程式保存控制點、方向、畫布尺寸、倍率、取樣範圍及測量值；數值可輸出 CSV。題目允許使用函式庫繪製這些已計算的測量圖。
- 渲染計時使用單調時鐘；計時範圍包含該 k 的放大、填色與平均，不包含 BMP 存檔及圖表輸出。各倍率使用相同最終尺寸與同一幾何場景，並說明計時方法。

### 錯誤與交付階段

- 使用具體錯誤型別區分無效尺寸、無效倍率、開放填色路徑、非有限幾何／顏色資料、尺寸或細分長度溢位，以及 I/O 失敗。
- 不宣稱固定陣列本身已帶來實測效能改善；效能由第三題測量支持。
- 第一階段交付共用工具庫、必要測試、小型可執行出圖示範及建置／執行說明。
- 後續前三題整合應完成本規格所有場景、測量、圖表與回答。首次工具庫示範不能視為完整前三題已完成。

## Testing Decisions（測試決策）

### 測試介面與原則

- 沿用已確認的工具庫公開介面，主要以「建立路徑 → 渲染覆蓋率 → 轉色 → 輸出並解碼 BMP」的端到端流程驗證；不增加僅供測試的抽象。
- 獨立數學規則與邊界條件在對應公開介面補充測試。測試不依賴私有欄位、內部迴圈、配置次數或算法分解方式。
- 好的測試使用可獨立判斷的幾何與數值結果，檢查外部可見行為。浮點比較使用清楚的數值容差；題目 0.1 px 與 0.5 px 門檻仍採嚴格小於。
- 現有工作區只有原始作業、術語與設計文件，沒有既有程式或測試先例。新增測試由公開行為與題目驗收條件建立。

### 覆蓋範圍

1. **矩陣與向量**：已知非方陣乘法、轉置、單位矩陣、內積與長度；尺寸不相容的乘法應在編譯階段被拒絕。
2. **點與線段**：位置／位移運算結果、投影在線段內及端點外的距離、零長度線段。
3. **Bézier**：端點、與獨立 Bernstein 公式的比較、中點細分前後參數對應的一致性、深度與線段數、密集取樣間距及指定方向的誤差。
4. **路徑**：開放／封閉與多子路徑；三次段反向不改幾何；內圈反向後資料位置保持一致。
5. **填色**：簡單輪廓、五頂點自交星形中心、多子路徑圓環同向／反向的中心結果、水平邊、共同頂點、畫布外輪廓。用自交案例防止誤用 even-odd。
6. **Image 與 Color**：數值／彩色實例的存取與列讀取、已知覆蓋率區塊平均、混色、輸出量化、無效倍率與尺寸。
7. **Supersampling**：k 為 1 不改變基本填色結果；各倍率回傳相同最終尺寸；可手算的局部區塊與圖形位置。
8. **BMP**：會產生列補齊的寬度、左右與上下顏色不同的圖案；由獨立解碼器檢查尺寸、通道與列方向，不只重算編碼器自己的標頭公式。
9. **作業整合**：逐項核對最低成果清單。目視確認淺層差異、接點比較、旋轉後無軸對齊邊、測量列位置與輪盤中心失真；核對原始數據與圖表對應。
10. **效能紀錄**：核對固定最終尺寸、所有 k 的計時結果及範圍；不把某個預期加速比或成長倍數寫成必須通過的測試。
