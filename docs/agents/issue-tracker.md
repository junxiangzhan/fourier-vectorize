# 本地任務追蹤

本專案使用本地檢查點與一票一檔，不向外部 tracker 發布。

- 規格：`docs/spec.md`
- 任務總覽與相依：`docs/checkpoints.md`
- 正式票：`.scratch/assignment-1151/issues/01-bmp.md` 至 `10-reproduce-report.md`
- 稽核：`docs/audit.md`、`output/evidence_manifest.json`
- 狀態：`ready-for-agent` → `in-progress` → `done`。只有前置票完成才可開工；`done` 必須附實際驗證證據。

外部 issue 編號不適用；code review 以使用者指定的文件及上述本地票為需求來源。
